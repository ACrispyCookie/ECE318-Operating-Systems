## File structure

### Helper script

To make the program easier to run, the `run.sh` script is used.

### Source files

The source files, the executable and the `Makefile` can be found in the `src` directory.

### Configurations

The default configurations directory where the processes are defined is the `confs` directory. Can be customized by changing the `CONFS_DIR` variable in the `run.sh`.

### Plots

The plots are generated by the `plot.py` script and saved in the `plots` directory  in the `plots/sjf` folder for the standard SJF algorithm and in the `plots/sjf-mod` for the variation. The `requirements.txt` lists the requirements of the `plot.py`.

### Output

The ouput is saved in the `outputs` folder. Can be customized by changing the `OUTPUT_DIR` in the `run.sh`.


## Installation & Usage

To execute the scheduler simulation and generate the related plots based on the output, you can use the `run.sh` helper script, which executes the `make` command with the appropriate parameters and also the `plot.py` script to generate the plots.

The `plot.py` file requires the python packages from the `requirements.txt` file to be installed. To set up the python dependencies for the first time, run the following commands in the root of the project:

```bash
python -m venv venv
```

```bash
# Linux/MacOS
source venv/bin/activate

# Windows (CMD)
venv\Scripts\activate.bat

# Windows (PowerShell)
venv\Scripts\Activate.ps1
```

```bash
pip install -r requirements.txt
```

Finally, you can run the run.sh script:

```bash
bash run.sh
```


## Options

To view all the available options, use the `--help` flag:

```bash
bash run.sh --help
```

The available options are the following:

| Option | Description |
|:-------|:------------|
| `--config=FILE` | Use the specified configuration file. |
| `--no-goodness` | Disable the goodness algorithm. |
| `--debug` | Enable debugging using gdb. |
| `--no-plot` | Do not run the plot script. |
| `--nice` | Calculate timeslice for each task based on its 'NICE' value. |
| `--timeslice=N` | Set the timeslice value for each process (in jiffies).<br>**Default:** `N=10`. |
| `--hide=FLAGS` | Prevent specific graphs from displaying. Combine any of these flags:<ul><li>`g` - Hide Gantt chart</li><li>`b` - Hide Expected Burst graph</li><li>`c` - Hide CPU Usage graph</li><li>`s` - Hide Goodness Score graph</li><li>`all` - Hide all graphs</li></ul> |
| `--cpu-graph-slice=N` | Set the slice size for the CPU graph (in milliseconds).<br>**Default:** `N=500`. |
| `--burst-graph-slice=N` | Set the slice size for the Burst graph (in milliseconds).<br>**Default:** `N=3000`. |
| `--help` | Show this help message. |


The most important option is the `--no-goodness` option, which disables the goodness score metric, determining the next best process based only on the expected burst metric.
